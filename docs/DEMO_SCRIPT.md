# Content Studio Room: 2-Minute Demo

## 0:00-0:15 — Setup
Open Discord and show the `#studio-content` room with one human and the three
Switch agents visible: research, script, and review.

## 0:15-0:35 — Human starts the job
Post this in a thread:

> Create a 60-second video about why hydration matters during workouts.

Address `@studio-research` by name.

## 0:35-0:55 — Research hand-off
Show the research agent return 5-7 points with explanations and address
`@studio-script` by name with the research.

## 0:55-1:20 — Script and review
Show `@studio-script` post the Hinglish hook, three points, and CTA, then
address `@studio-review`. Show the reviewer return a clear pass or a specific
revision checklist.

## 1:20-1:45 — Revision loop
If it fails, request one visible revision. Show `@studio-review` send fixes to
`@studio-script`, and the script agent post a revised script back for review.

## 1:45-2:00 — Human approval
After the reviewer passes the script, reply explicitly:

> Approved.

Show the reviewer or room mark the thread complete. End on the full visible
research -> script -> review -> human approval thread.
